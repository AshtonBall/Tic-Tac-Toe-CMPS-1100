Tic Tac Toe

This is a game of Tic Tac Toe that includes multiple interactions, game modes, and features. It runs entirely in the terminal, so nothing needs to be done besides open it and run it!
As the player (X), you play agaisnt the computer (O).

What it includes
- Play against a computer
- Board can be of size 3x3 to 10x10
- Multiple Game Modes
    - Classic: regular Tic Tac Toe; get a full row, column, or diagonal of the same symbol
    - Connect-K: select how many symbols must be in a row for a win
    - Square: win by making a 2x2 square of the same symbol
    - 4 Corners: obtain all four corners of the board to win
    - Multiple can and should be selected in a match
- Colored symbols
    - X is red
    - O is blue
- Computer interaction
    - blocks the player
    - prevents winning moves
    - chooses a random valid move
- Ability to forfeit during a game
- Can play multiple rounds and choose game settins each new round


How to Run
- Must haev Python installed (preferably Python 3)
- Open your coding terminal and open the TicTacToe2.py file or a folder it is within
- Follow the game's prompts to select game settings
- Play!

Controls
- Enter numbers for board size, game mode, and Connect-K if applicable
- Enter the number of the grid square you wish to claim
- Type "forfeit" during a match to quit if desired
- After a round, type "y" to start another round or "n" to end the program

Includes a test file with multiple unit tests
- All implemented tests pass and the game works as inteded!
